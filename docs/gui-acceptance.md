# DSH 圖形介面驗收

這份檢查表驗證實際顯示與操作。HTTP 成功、模組載入或原始碼測試都不能代替它。
目前既有工具的 DSH 瀏覽器存取限制尚未解除；沒有使用其他工具繞過。
可由使用者手動驗收，或在工具存取獲准後由代理操作。驗收紀錄須如實標明操作者。

先使用隔離實驗室的 DSH 網頁設定檔，確認左側有「架構實驗室」。不要在正式課程
對話輸入測試提示。整份檢查只用固定離線範例；付費按鈕應維持停用。
若自行從已完成安裝的原始碼目錄啟動，可使用 `npm run web`；此操作由操作者自行
開啟頁面，不表示代理已取得瀏覽器操作權限。

| 項目 | 操作與應看到的結果 |
| --- | --- |
| 入口與版面 | 開啟「架構實驗室」，窄視窗與深／淺色主題下可讀取文字與表格，沒有被遮住的主要操作。以 Tab 可移到按鈕與表單。 |
| 四種配方 | 逐一選 A/B/C/D；選取狀態正確。各執行一次固定離線驗證，看到配方、狀態、外部測試與模型宣稱分開呈現。固定範例不得顯示為正式研究勝率。 |
| 停止與恢復 | 另一次離線驗證出現執行中後按停止；紀錄保留。十分鐘內按明確恢復，新增嘗試而非覆蓋舊紀錄，累計請求不重置。若已逾十分鐘，應拒絕恢復並說明原因。 |
| 重開讀回 | 完成或停止任務後關閉再開啟管理介面；配方、完成／中斷紀錄與證據仍可讀取。管理服務實際重啟需另記，單純重新整理不能當成程序重啟。 |
| 證據與報告 | 開啟證據視窗，切換紀錄／原始報告／判定等內容，再關閉。匯出 JSON，核對配方與次數；沒有有效試驗時不可宣稱架構勝出。 |
| 日常草稿 | 建立空白專案，輸入繁體中文及換行的任務內容，儲存後重新整理仍存在。付費啟動仍停用；固定離線範例不得冒充該自訂任務的答案。 |
| 日常成果 | 執行固定離線範例，檢視變更、採用成果，再匯出至不存在的新資料夾。核對檔案存在；相同目的資料夾再次匯出應被拒絕。 |
| 訊息可讀性 | 連線失敗、正在清理、缺少依賴、超出限制或拒絕覆蓋，均要有可理解的訊息，且不把失敗顯示為完成。 |

回報時請列出版本、使用的 DSH 設定檔／介面、通過項目、失敗項目、實際操作步驟與
錯誤文字。不要提供金鑰或私人課程資料。可在回報中寫明哪些項目尚未做；未驗證項目
會繼續保持未完成。人工回報只作人工驗收證據，不會被標為代理親自操作的結果。
